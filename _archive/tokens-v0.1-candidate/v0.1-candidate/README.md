# Archived — v0.1-candidate tokens (March 2026)

**Superseded 2026-08-06 by v1.0.0. Do not consume these.**

These are the original candidate tokens: the teal/blue palette (`#0096BC`, `#1C5AEC`),
Albert Sans / Plus Jakarta Sans / Sedgwick Ave, and the gradient set.

They were retired after a ground-up re-derivation of the visual identity. The short
reason: the palette read as generic. A competitive scan of 22 verified peers found the
field already splits between a dark-AV uniform and trust-blue templates, and the teal/blue
system sat inside that second group rather than apart from it.

The replacement is one accent (`#FC4C13`) with everything else neutral, and all remaining
colour supplied by the photography.

Kept for provenance so the change is auditable. `gradients.json` has no v1.0.0 equivalent —
the system no longer uses gradients at all.
