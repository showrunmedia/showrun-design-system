# Logos — v1.0.0

Showrun's existing mark, generated from the source SVGs. Not redrawn.

```
svg/       icon + horizontal lockup, three colourways
png/       icon 32–1024px high · lockup 400–2400px wide
favicon/   square and padded, 16–512px, on charcoal / paper / vermilion
```

**Colourways:** ink `#141416` · white `#FFFFFF` · vermilion `#FC4C13`

**The mark is 1.4:1.** Pad it into a square; never scale it to fit one. The favicon files
are already padded correctly.

**Do not** distort, rotate, recolour outside the three colourways, or place on busy imagery
without a contrast ground.

**Retired:** the gradient lockups using `#2563EB → #0EA5E9`. That gradient is the blue the
brand moved away from in v1.0.0. The mark geometry itself is unaffected.
